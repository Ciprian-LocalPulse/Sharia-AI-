# دليل المساهمة

**المؤلف: Ciprian Ștefan Pleșca**

شكرًا لاهتمامك بالمساهمة في Sharia-AI! يجمع هذا المشروع بين الكود
ومواضيع حساسة من الفقه الإسلامي — لذلك لدينا بعض القواعد الإضافية
مقارنة بمشروع مفتوح المصدر نموذجي.

## أنواع المساهمات المرحَّب بها

- **توسيع معجم معالجة اللغة الطبيعية** (`nlp/riba_detector.py`) —
  مصطلحات إضافية للربا/الغرر/الميسر، خاصة اللهجات الإقليمية أو الصيغ
  التعاقدية الخاصة بولاية قضائية معينة.
- **وحدات فرز جديدة** — مثل الامتثال للصكوك (السندات الإسلامية)،
  التكافل (التأمين الإسلامي).
- **تحسينات دقة معالجة اللغة الطبيعية** — الترميز، الاشتقاق، معالجة
  الغموض الصرفي العربي.
- **التوثيق والترجمات** (الإنجليزية، الفرنسية، لغات أخرى مُتحدَّث بها
  في منطقة الشرق الأوسط وشمال أفريقيا).
- **اختبارات إضافية**، خاصة حالات الانحدار للإيجابيات/السلبيات الكاذبة
  المكتشَفة في الإنتاج.

## قواعد خاصة بمحتوى الشريعة

1. **يجب أن يكون أي تعديل على العتبات في `screening/rules.py` أو على
   المعجم في `nlp/riba_detector.py` مصحوبًا بمصدر منهجي** (معيار
   AAOIFI، منهجية مؤشر، أو مرجع إلى نص قانوني معترف به) في وصف طلب
   السحب (Pull Request).
2. **لا تُضِف تصريحات تُصدر فتوى** (مثل: "س حرام قطعًا في جميع
   المذاهب الفقهية"). صِغ الأمور بحياد، مع الإشارة إلى التفسير السائد
   وذكر وجود آراء مختلفة حيثما كانت معروفة.
3. **يجب اختبار المساهمات في معجم معالجة اللغة الطبيعية للتحقق من عدم
   وجود إيجابيات كاذبة** — سيتم رفض مصطلح مُضاف دون حالة اختبار تتحقق
   أيضًا من عدم التفعيل على كلمات مشابهة (متجانسات، مشتقات).

## سير العمل التقني

```bash
git clone https://github.com/your-org/sharia-fintech-ai.git
cd sharia-fintech-ai
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"

# قبل الإيداع (commit):
ruff check src tests
mypy src
pytest --cov=sharia_ai --cov-report=term-missing
```

تعمل جميع طلبات السحب تلقائيًا عبر CI (`.github/workflows/ci.yml`) على
بايثون 3.10 و3.11 و3.12.
